# Інструкція розгортання сайту «Wind to the East» на сервері

Цей сайт є повністю автономним клієнтським додатком (Single Page Application). Для його роботи підходить будь-який віртуальний сервер (VPS) на базі Linux (Ubuntu/Debian).

---

## Варіант 1: Запуск через Docker (Найпростіший)

Якщо на твоєму сервері встановлено Docker, розгортання виконується буквально двома командами:

```bash
# 1. Зібрати легкий Docker-образ сайту
docker build -t wind-to-the-east .

# 2. Запустити сайт на порту 80
docker run -d --name wind-app -p 80:80 --restart unless-stopped wind-to-the-east
```

Після цього сайт одразу відкривається за IP-адресою твого сервера (або підключеним доменом) у будь-якому браузері на будь-якому пристрої!

---

## Варіант 2: Класичний Nginx на сервері

Якщо ти не хочеш використовувати Docker:

```bash
# 1. Встановити Nginx на сервері (якщо ще не встановлено)
sudo apt update && sudo apt install -y nginx

# 2. Зібрати проєкт на комп'ютері або сервері
npm run build

# 3. Скопіювати вміст папки dist/ у папку веб-сервера
sudo rm -rf /var/www/html/*
sudo cp -r dist/* /var/www/html/

# 4. Перезапустити Nginx
sudo systemctl restart nginx
```

---

## Локальний перегляд на твоєму комп'ютері

Щоб відкрити сайт локально на Windows (використовується портативний Node.js із папки `.tools\node`), просто запусти у терміналі:

```powershell
.\start.bat
```

*(Або якщо Node.js встановлено глобально в системі: `npm run dev`)*

Vite виведе посилання виду `http://localhost:5173/`, на яке можна клікнути й одразу користуватися сайтом у браузері.
