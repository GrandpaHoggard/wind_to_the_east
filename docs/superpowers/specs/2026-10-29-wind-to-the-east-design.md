# Design Document: Wind to the East (Метеомоніторинг та вітер до 5000м)

- **Дата:** 2026-10-29
- **Тема:** Спеціалізований веб-сервіс моніторингу погодних умов, висотного вітру та хмарності
- **Статус:** Очікує фінального затвердження (Ready for Final Approval)

---

## 1. Задум та мета (Intent & The Why)

Створення спеціалізованого веб-додатку для точного моніторингу та прогнозування погоди у будь-якій точці планети. Проєкт орієнтований на польотні, навігаційні та тактичні задачі (БПЛА, авіація, польове планування), де критично важливими є:
- детальний висотний зріз атмосфери від поверхні землі до 5000 метрів (швидкість, пориви, напрямок вітру, температура та хмарність на кожному ешелоні);
- підтримка військової системи координат MGRS нарівні з WGS 84;
- нульові вимоги до встановлення клієнтом (доступ з будь-якого пристрою через браузер без завантажень додатків).

---

## 2. Цілі, не-цілі та анти-цілі (Goals, Non-Goals, Anti-Goals)

### Цілі (Goals)
1. **Глобальний вибір локації:** можливість обрати точку кліком по інтерактивній карті світу, пошуком населеного пункту або прямим введенням координат.
2. **Підтримка систем координат:** повноцінна двостороння підтримка **WGS 84** (десяткові градуси) та **MGRS** (Military Grid Reference System) з автоматичною конвертацією.
3. **Погодинний прогноз параметрів вітру на всіх висотах до 5000 м:**
   - **Швидкість вітру** у **м/с** для кожного висотного рівня;
   - **Пориви вітру** у **м/с** для кожного висотного рівня до 5000 м (розраховуються за моделлю авіаційного зсуву вітру *Wind Shear* та приземної турбулентності: там, де є різкий градієнт швидкості/напрямку між шарами — порив більший, у стабільному потоці порив дорівнює швидкості вітру);
   - **Напрямок вітру** за **класичним метеорологічним стандартом флюгера** («звідки дме вітер») із графічною стрілкою та точним числовим значенням у градусах (`0°–360°`).
4. **Висотні профілі атмосфери (вкладка «Профіль вітру» та ешелони):**
   - **Хмарність (%)** на кожній висоті від поверхні до 5000 м AGL (розраховується на основі висотних шарів хмарності Open-Meteo та відносної вологості на ізобаричних рівнях);
   - **Температура повітря (°C)** на кожній висоті (за термодинамічним градієнтом та даними ізобаричних рівнів);
   - Рівні висот (AGL): поверхня, 25м, 50м, 75м, 100м, 120м, 150м, 200м, 300м, 500м, 1000м, 1500м, 2000м, 3000м, 5000м.
5. **Висотний базис AGL:** усі висотні ешелони відраховуються **від поверхні землі (AGL — Above Ground Level)** з урахуванням рельєфу місцевості.
6. **Комплексні метеопараметри:** погодинна вологість (%), кількість опадів (мм), ймовірність опадів (%) та загальний стан хмарного покриву.
7. **Часове вікно аналізу:** режим поточної погоди («тут і зараз») та гнучкий фільтр періоду із заданням дати й години початку та дати й години завершення. Формат дати: суворо `день\місяць\рік` (`ДД\ММ\РРРР`).
8. **Кросплатформність та нульове встановлення:** повна адаптивність інтерфейсу під ПК, планшети та смартфони без встановлення додаткових додатків користувачем.
9. **Темна естетика:** стильний, контрастний темний авіаційний інтерфейс у стилі UAV Forecast.

### Не-цілі для першої версії (Non-Goals)
- Авторизація користувачів, паролі та реєстрація (сервіс відкритий і готовий до роботи без входу).
- Список обраних локацій (зафіксовано в [backlog.md](file:///d:/vibecode/projects/wind_to_the_east/backlog.md) для наступних релізів).
- Підключення приватних апаратних метеодатчиків.

### Анти-цілі (Anti-Goals)
- Створення важких нативних додатків (Android APK / iOS IPA), що вимагають завантаження з магазинів чи дозволів пристрою.
- Використання закритих платних погодних API з лімітами або обов'язковими кредитними картками.
- Перевантаження архітектури важкими базами даних та складною бекенд-інфраструктурою на початковому етапі.

## 3. Обмеження та формати (Constraints)

- **Одиниці швидкості та поривів вітру:** виключно **метри на секунду (м/с)**.
- **Одиниці температури:** градуси Цельсія (°C).
- **Одиниці хмарності:** відсотки (%).
- **Відображення напрямку вітру:** метеорологічний флюгер (вказує звідки дме вітер) + градуси (наприклад: `↗ 45°`).
- **Формат дати:** `ДД\ММ\РРРР` (наприклад, `29\10\2026`).
- **Діапазон висот:** від поверхні (0 м) до 5000 м AGL.
- **Доступність:** робота у будь-якому сучасному веб-браузері (Chrome, Safari, Firefox, Edge) за єдиним посиланням без встановлення програм.

---

## 4. Архітектурне рішення та розгортання

- **Клієнтський SPA на Vue 3 + Tailwind CSS + Leaflet:**
  - Open-Meteo API дозволяє прямі виклики з браузера без секретних ключів.
  - Розрахунок MGRS ↔ WGS 84 та авіаційної моделі поривів/хмарності на висотах відбувається клієнтським кодом у браузері.
  - Нульове навантаження на сервер, миттєве завантаження на будь-якому пристрої.
- **Серверна частина:**
  - Готовий веб-бандл підготовлено для розгортання на будь-якому сервері (через **Nginx** або легкий **Docker** контейнер). Додається готова інструкція запуску.

## 5. Структура інтерфейсу та функціональні модулі

1. **Шапка (Header):**
   - Назва та логотип (`Wind to the East`).
   - Рядок поточної обраної точки: координати у WGS 84 та MGRS.
2. **Панель керування та фільтрів:**
   - Поле вибору локації (пошук населеного пункту або ручний ввід координат із перемикачем WGS 84 / MGRS).
   - Фільтр часового діапазону: вибір дати (`ДД\ММ\РРРР`) та години початку / завершення.
   - Селектор висоти вітру (поверхня та градація висот аж до 5000м AGL).
3. **Основна робоча зона (Вкладки):**
   - **«Прогноз»:** головна зведена погодинна таблиця (час, швидкість і пориви вітру в м/с з флюгерною стрілкою і градусами, температура, опади та їх ймовірність, хмарність, вологість для вибраної висоти).
   - **«Профіль вітру»:** детальна вертикальна таблиця всіх висот (від землі до 5000 м AGL) для обраної години, що містить:
     - висоту AGL;
     - швидкість вітру (м/с);
     - пориви вітру (м/с);
     - напрямок вітру (стрілка флюгера + градуси);
     - температуру (°C);
     - хмарність (%).
   - **«Карта»:** інтерактивна карта OpenStreetMap/Leaflet із можливістю поставити маркер кліком або переглянути розташування.
4. **Картка поточної погоди («Тут і зараз»):**
   - Експрес-панель ключових умов на поточну годину для швидкої оцінки польотної обстановки.

## 6. Що залишається на розсуд розробника (Left to Builder)

- Алгоритм поєднання даних ізобаричних рівнів тиску Open-Meteo з геопотенціальною висотою та моделювання зсуву вітру (Wind Shear) для розрахунку поривів на висотах.
- Інтерполяція профілю хмарності (%) по висотах за шарами (low/mid/high) та відносною вологістю.
- Контрастна кольорова гама темної теми Tailwind CSS (зелені/червоні/нейтральні акценти для читабельності).
- Конфігураційні файли `Dockerfile` та `nginx.conf` для швидкого розгортання на сервері.
